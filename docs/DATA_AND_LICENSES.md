# Sources, licences and presentation boundaries

## Footage

The selected source is **Multiview Extended Video with Activities (MEVA), KF1**,
camera G328, original ground-camera recordings transcoded as release `r13`.
The three exact source files, byte lengths, SHA-256 hashes, time ranges and crop
are recorded in `configs\meva-g328.json`.

Attribution: "Multiview Extended Video with Activities" (MEVA) dataset by
Kitware Inc. and the Intelligence Advanced Research Projects Activity (IARPA).
Licensed under Creative Commons Attribution 4.0 International.

- Dataset: <https://mevadata.org/>
- Licence text: <https://mevadata.org/resources/MEVA-data-license.txt>
- Licence: <https://creativecommons.org/licenses/by/4.0/>
- Release/download instructions: <https://mevadata.org/resources/README-meva-kf1-data.html>
- Annotations: <https://gitlab.kitware.com/meva/meva-data-repo>

If presenting media, identify the modifications: selected time range, cropping,
resizing, transcoding, overlays and any redaction. Keep attribution and licence
links with the presentation. Do not imply dataset-author endorsement.

MEVA was collected using actors and includes staged scenarios. The licence
permits commercial copyright reuse, adaptation and sharing with attribution;
it is not a warranty of all privacy/publicity or other third-party rights.
Public presentation requires a separate privacy/rights review and any necessary
redaction. The local replay is not clearance to publish.

Original media and exports remain untracked. Do not republish the source corpus,
GPS data, person-identity material, faces or plates from this project. No identity
or plate strings are generated.

The text annotations in `reference` are derived MEVA annotations, shared under
CC BY 4.0 with the dataset attribution above, not relicensed as MIT project
code. The initial labels were prepared by AI for human review; they are not
represented as the dataset authors' exhaustive human ground truth.

## README screenshots

The images in `docs/screenshots` are actual captures of this application's UI
using original synthetic fixtures under the project's MIT licence. They do
not include MEVA frames, private uploads or real plate histories. Repeated
dashboard views replay the same scripted test recording at different times,
not independent camera feeds. Monitoring records are explicitly synthetic.
The images demonstrate the interface, not model accuracy or ANPR performance.

Regenerate them with `npm.cmd run screenshots` in `viewer`. The command uses
an isolated temporary database and browser, performs no model inference, and
does not touch the operator's database. Screenshots are generated only by this
explicit command, not the normal browser-test run.

## Model and tracking

The artificial plate-event examples under `examples` and generated by the
operator API are original synthetic project fixtures under MIT. They do not
come from MEVA, contain no asserted real vehicle identities and substantiate
no ANPR accuracy. Real operator imports require separate authorization and
stay private; see `OPERATIONS.md`.

- Detector weights: `PekingU/rtdetr_r18vd`, revision
  `ac77a11ff0170a41b771c03264987f8ce2b0d753`. The **weight model card itself**
  declares Apache-2.0:
  <https://huggingface.co/PekingU/rtdetr_r18vd/blob/ac77a11ff0170a41b771c03264987f8ce2b0d753/README.md>.
- RT-DETR upstream implementation: Apache-2.0:
  <https://github.com/lyuwenyu/RT-DETR/blob/main/LICENSE>.
- Transformers: Apache-2.0; PyTorch/torchvision: BSD-style project licences.
- Tracker: Supervision 0.25.1, MIT. Its ByteTrack implementation derives from
  ByteTrack, MIT, Copyright (c) 2021 Yifu Zhang. Preserve both notices:
  <https://github.com/roboflow/supervision> and
  <https://github.com/ifzhang/ByteTrack/blob/main/LICENSE>.
- PyAV: BSD-3-Clause; its wheel links FFmpeg, whose build/codec licences are

- The local operator API uses FastAPI, Starlette and Uvicorn; SQLite is from
  Python's standard library. No new model/weight or camera dataset is fetched

Dependencies are installed into this project's environment, not vendored.
The locked versions, selected model artifact hashes and installed metadata
are recorded with runs. Original project code is MIT; that does not relicense
any third-party data, weights, software or notices.

## Resource accounting

Approved: local CPU/RTX 3060 inference only, no training or paid/cloud services;
5 GiB cumulative downloads including dependencies, and at most 30 minutes per
processing run.

Initial footage qualification fetched eight short vehicle exemplars
(35,925,875 bytes) and three full G328 clips (351,376,818 bytes). The short
exemplars are scouting material, not benchmark inputs. The base Python setup
downloaded approximately 120 MiB including a local Python interpreter.

The Windows GPU wheel was 2,915,418,348 bytes, plus a 6,227,539-byte torchvision
wheel and the other locked dependencies. The pinned model files total
80,919,362 bytes. The fetch ledger accounts/reserves 4,375,886,658 bytes out of
5,368,709,120 after setup. Its initial 4 GiB reserve conservatively covers
external setup, scouting and pre-fetched sources; this is not an exact traffic
meter. No browser download was needed because installed Edge was used.

Keep caches under the project on the data drive. Check remaining download
budget before installing model/browser dependencies or fetching weights.
Never synchronize the entire public S3 bucket.
